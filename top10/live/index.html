Overlays live TOPSIDE

Réglez le sujet et l'heure, puis pour chaque écran cliquez « Copier le lien OBS » et collez-le dans une source Navigateur d'OBS (1920×1080). Les zones rayées sont transparentes : mettez-y vos caméras, la vidéo et le tchat.

Dans OBS

  1. Créez une scène par écran (Attente, Réaction, Tweets, Tier list, Discussion, Pause, Fin).
  2. Dans chaque scène, ajoutez d'abord vos sources (caméras, capture de la vidéo, tchat), puis en dernier une source Navigateur : collez le lien, largeur 1920, hauteur 1080. Elle doit être tout en haut de la liste des sources.
  3. Placez et redimensionnez la caméra, la vidéo et le tchat dans les cadres (l'aperçu ici montre où).
  4. Tier list : clic droit sur la source Navigateur → Interagir. Tapez un nom, « Ajouter », puis glissez les photos dans les lignes. Le classement reste enregistré.
  5. Après avoir changé un réglage ici, recopiez le lien dans la source (ou clic droit → Propriétés → coller).

Alertes Twitch, derniers events et tchat (StreamElements)

Twitch n'envoie les follows, subs et bits qu'à des services comme StreamElements. On y colle trois widgets dans la DA. Voir les alertes en test

  1. Créez un compte sur streamelements.com avec Twitch, puis Streaming tools → Overlays → New overlay (1920×1080).
  2. Ajoutez + → Static/Custom → Custom widget, puis Open editor. Dans les onglets HTML, CSS, JS et Fields, collez les 4 fichiers du dossier live/streamelements/alertes/. Enregistrez.
  3. Faites pareil avec streamelements/evenements/ (ligne « dernier follow / sub / bits ») et streamelements/tchat/ (tchat).
  4. Placez les widgets (tchat dans le cadre « Tchat »), enregistrez, copiez le lien de l'overlay StreamElements et ajoutez-le dans OBS en source Navigateur 1920×1080, au-dessus de tout.
  5. Testez avec le bouton Emulate de StreamElements (simule un follow, un sub, des bits…).
